# Calc-Pi

This project calculates π with an arbitrary number of decimal places using the Gregory-Leibniz series and the GNU Multiple Precision Arithmetic Library (GMP).

## Installation

1. Install the GMP library:
# sh
sudo pacman -S gmp

2. Compile the project:
# sh
make

## Usage

Run the compiled program:
# sh
./bin/calculate_pi

Enter the desired number of decimal places when prompted.
